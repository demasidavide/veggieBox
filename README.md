# 🥗 VeggieBox

Un'applicazione web per scoprire, salvare e organizzare ricette vegetariane e vegane, con funzionalità intelligenti per la gestione della spesa.<br>
<strong>Disponibile in Italiano e Inglese.</strong>

## 📋 Descrizione

VeggieBox è una piattaforma dedicata agli amanti della cucina plant-based che permette di esplorare un vasto database di ricette vegetariane e vegane. L'applicazione offre strumenti pratici per pianificare i pasti e semplificare la spesa settimanale.

## ✨ Funzionalità Principali

- **🔍 Ricerca Ricette**: Esplora un ampio catalogo di ricette vegetariane e vegane
- **💾 Salvataggio Ricette**: Crea la tua collezione personale di ricette preferite
- **🛒 Lista della Spesa Intelligente**: Calcolo automatico degli ingredienti necessari da tutte le ricette salvate
- **📥 Download & Condivisione**: Scarica o condividi facilmente la tua lista della spesa
- **📱 Interfaccia Intuitiva**: Design user-friendly e responsive

## 🛠️ Tecnologie Utilizzate

- **React**: Libreria JavaScript per la costruzione dell'interfaccia utente
- **Axios**: Client HTTP per le chiamate API
- **JavaScript (ES6+)**
- **Context API**
- **HTML5 / CSS3**
- **API**


## 🚀 Installazione

```bash
# Clona il repository
git clone https://github.com/tuousername/veggiebox.git

# Entra nella directory del progetto
cd veggiebox

# Installa le dipendenze
npm install

# Avvia l'applicazione in modalità sviluppo
npm start
```

L'applicazione sarà disponibile su `https://demasidavide.github.io/progetti/veggieBox/dist/`

## 📦 Build per Produzione

```bash
npm run build
```

Questo comando crea una build ottimizzata nella cartella `build/`.

## 🎯 Come Utilizzare VeggieBox

1. **Cerca ricette** utilizzando la barra di ricerca o naviga per categorie
2. **Salva le tue ricette preferite** cliccando sul pulsante salva
3. **Visualizza la lista della spesa** generata automaticamente con tutti gli ingredienti
4. **Scarica o condividi** la lista per portarla sempre con te
